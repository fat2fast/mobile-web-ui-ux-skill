# Contributing

We welcome focused, evidence-based improvements to **mobile web UX**, not unrelated design-system expansion.

1. Open an issue documenting the user task and observable mobile problem.
2. Suggest a pattern with when-to-use, when-not-to-use, alternatives and accessibility considerations.
3. Add or update a scenario in `evals/scenarios/`.
4. Keep rules concise and framework-agnostic; avoid broad UI rewrites and hard-coded visual aesthetics.
5. Run `python scripts/validate_skill.py` before submitting a PR.

Do not copy third-party content without license and attribution. Do not claim quantitative UX gains without test evidence. No user or private repository data should be committed.
