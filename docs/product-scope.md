# Product Scope

## Mission

Help a non-designer use an AI coding agent to **improve mobile web UI/UX** of an existing responsive site or build a mobile view for an existing web product. The agent should understand tasks, make sensible decisions, implement scoped changes and verify outcomes.

## Primary user

- Vibe coder / solo founder who can describe product features but cannot prescribe UX patterns.
- Developer responsible for a working web application with acceptable desktop behavior and suboptimal phone usability.

## Job to be done

"My website already works and adjusts to phones, but users have trouble accomplishing tasks. Make the mobile experience more intuitive without breaking what I have."

## Core distinction

- Responsive layout: *Does it fit?*
- Mobile web usability: *Can someone accomplish their task easily on a phone?*
- Installed PWA: *Does the mobile experience remain coherent when launched standalone, offline or with device-specific browser constraints?*

## Product promise

An agent equipped with this skill can interpret a simple request, focus on the highest-impact mobile problems, select context-appropriate patterns and produce changes plus explicit evidence.

## Principles

1. User tasks before visual novelty.
2. Existing code and semantics before redesign.
3. Web interaction conventions before native mimicry.
4. One thoughtful UX decision before ten generic checklist items.
5. Evidence and reproducible tests before claims of improvement.
6. Non-designers should not be asked to make professional design choices by default.

## Success signal

Given an existing responsive reference app and a simple non-designer request, the agent completes a defined mobile task improvement with no lost functionality or desktop regressions, and reports valid verification evidence. Measured user task completion may require manual usability testing.
